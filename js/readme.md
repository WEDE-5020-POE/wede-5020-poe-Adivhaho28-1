Snatche Wigs Website
Project Overview
Snatche Wigs is a small beauty business website developed to showcase and sell synthetic and human hair blend wigs online. The website was created using HTML, CSS, and focuses on responsive design, user experience, and modern styling.
JavaScript Functionality
The Snatche Wigs website uses JavaScript to improve interactivity, user experience, and form validation. The script handles product search, image viewing, ordering system, and form validation.
Product Search
A live search function filters products based on user input.

How it works:

Captures text from the search bar (#searchInput)
Converts input and product text to lowercase
Shows matching products and hides non-matching ones
Image Lightbox Gallery
Allows users to click on product images to view them in full screen.

Features:

Opens selected image in overlay
Displays image in larger view
Can be closed by user
Order Modal System
A popup order form is used to improve user experience.

Features:

Opens modal when user clicks “Order Now”
Auto-fills selected product name
Closes modal when clicking outside or using close button
Auto product fill
Automatically fills the product field when passed through URL.


Functionality:

Reads URL parameters using URLSearchParams
Inserts product name into form field automatically
Form Validation
 - Order form validation
 - enquiry form validation
 - contact form validation
Scroll to Top Button
A button appears when the user scrolls down.

Features:

Appears after scrolling 300px
Smooth scroll back to top
Modal behaviour
Clicking outside modal closes it
Improves user experience and navigation flow
