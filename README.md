# Snatche Wigs Website
## Project Overview
Snatche Wigs is a small e-commerce-style beauty website designed to showcase and sell synthetic and human hair blend wigs. The website was built using HTML, CSS, and JavaScript, with a focus on responsive design, usability, and interactive features.

## Technologies Used
- HTML for structure
- CSS for styling and responsive design
- JavaScript for interactivity and form validation
## CSS Features
The website uses an external stylesheet (style.css) to manage layout, design, and responsiveness.
### Styling Features
- CSS reset for consistent styling across browsers
- Flexbox layout for navigation, product sections, and gallery
- Hero section with centered layout and responsive scaling
- Product cards with hover effects and shadow styling
- Styled forms with input focus effects
- Modal popup styling for order system
- Lightbox image viewer styling
- Scroll-to-top button styling
- Search bar styling with focus effects
- Footer styling for consistent branding
## Responsive Design
The website is fully responsive using media queries.
### Tablet (max-width: 768px)
- Navigation changes to vertical layout
- Product cards stack in a single column
- Hero section height and text size reduced
- Gallery images resized for better fit
### Mobile (max-width: 480px)
- Reduced font sizes for readability
- Product cards become full width
- Gallery displays in a single column layout
- Search bar expands to improve usability
## UI and UX Improvements
- Hover effects on buttons, navigation links, and product cards
- Smooth transitions for interactive elements
- Consistent color scheme across all pages
- Improved spacing and alignment throughout the layout
## JavaScript Functionality
- JavaScript is used to enhance interactivity and improve user experience.
## Product Search
- Filters products dynamically based on user input
- Case-insensitive search functionality
- Shows and hides product cards based on matches
## Image Lightbox
- Allows users to view images in full-screen mode
- Opens image overlay on click
- Provides option to close image viewer
## Order Modal System
- Popup modal for placing orders
- Automatically fills selected product name
- Can be closed using button or clicking outside the modal
## Auto Product Fill
- Uses URL parameters to auto-fill product field
- Example:
order.html?product=Straight Wig
## Form Validation
### Order Form
- Validates name field
- Validates email field
- Ensures quantity is at least 1
- Displays error messages for invalid input
### Enquiry Form
- Validates name and email fields
- Requires message length of at least 10 characters
### Contact Form
- Validates name, email, and message length
## Scroll-to-Top Button
- Appears after scrolling down the page
- Smooth scroll back to top functionality
## Confirmation System
- Displays success message after form submission
- Prevents page reload using JavaScript event handling
## Modal Behaviour
- Opens and closes order modal
- Allows closing by clicking outside the modal
- Improves overall user interaction flow

A console message is displayed when the website loads:

## Deployment
- The website is deployed using Netlify for hosting and live preview.
